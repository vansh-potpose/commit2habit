# Commit2Habit

[Live Demo](https://commit2habit.vercel.app/)

Commit2Habit is a powerful habit-tracking app designed to help you stay on top of your goals. It combines task tracking, data analysis, and AI-generated reports to provide deep insights into your habits and performance. The app is inspired by the "Solo Leveling" system, where users gain points and level up by completing tasks.

## Features

### 1. **Dashboard**
- Displays your profile picture, name, and a customizable title (editable in the settings).
- Tracks user abilities with points. Complete tasks to gain points and level up, inspired by the "Solo Leveling" concept.

### 2. **Habits**
- Includes three editable habit templates for different days, such as regular days, Sundays, or off days.
- Allows users to assign points and add descriptions to each habit.
- Users can save daily habit data, including optional notes to aid in analysis.
- Features two dynamic graphs:
  - **Percentage of points scored** for the day.
  - **Last 7 days progress data**.

### 3. **Reports**
- Provides an easy-to-use view of the last 30 days of habit data.
- AI-generated reports analyze habit performance and provide insights, including reasons for missed habits.

### 4. **Settings**
- Customize profile details, such as profile picture, title, and abilities.
- Edit habit templates and rename them to fit your needs.
- Add, edit, or delete abilities. Abilities can be deleted by double-clicking.

## Technologies Used
- **Frontend**: Next.js, Tailwind CSS
- **Backend**: Appwrite for database and authentication
- **Charts**: Dynamic graphs for visual progress tracking
- **AI Integration**: Groq AI for report generation and habit analysis

## How It Works
1. Track your habits daily by saving progress and notes.
2. Gain points and level up your abilities by completing tasks.
3. Analyze your performance with AI-generated insights and visual graphs.
4. Use the settings to personalize your experience.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/commit2habit.git
   ```
2. Navigate to the project directory:
   ```bash
   cd commit2habit
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
